# Kronotime Feed

Feed de productos de https://kronotime.com para Google Merchant Center, actualizado cada hora con GitHub Actions.

- `kronotime.xml`: el feed (un ítem por producto), para cargar en Merchant Center.
- `feed.json`: datos crudos y caché de códigos de barras.

URL del feed (GitHub Pages):

```
https://matiasugarte-oss.github.io/Kronotime-Feed/kronotime.xml
```
